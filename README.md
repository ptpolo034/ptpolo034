# Hola, soy Henry Polo 👋

Soy programador colombiano y me dedico a hacer software para negocios reales: programas de escritorio y aplicaciones web
que se usan todos los días en un parqueadero, en un negocio de boletas o en un punto de venta.

Trabajo sobre todo con **Java y Spring Boot**, y me gusta que lo que construyo tenga pruebas automáticas, sea fácil de
usar y se pueda instalar sin dolores de cabeza.

## Cómo trabajo

- Escribo pruebas automáticas para las reglas del negocio (cobros, liquidaciones, licencias), para poder cambiar cosas sin miedo.
- Cuido la experiencia de uso: flujos rápidos con teclado, mensajes claros en español y diseños que funcionan en pantallas pequeñas.
- Mantengo cada proyecto con su lista de tareas y porcentaje de avance.
- Los secretos y los datos de clientes nunca van al repositorio.
